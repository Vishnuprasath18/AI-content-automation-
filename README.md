# 🚀 AI Social Media Creator

An AI-powered social media content automation tool built using **Python**, **Streamlit**, and **NVIDIA NIM APIs** with **Llama 3.1 70B**.

This application helps businesses, creators, and marketing teams generate engaging social media content instantly for multiple platforms like LinkedIn, Instagram, and Twitter/X.

---

## ✨ Features

- 🎯 Generate platform-specific social media posts
- 🎭 Multiple content tones
  - Professional
  - Casual
  - Marketing
  - Funny
- 📱 Multi-platform support
  - LinkedIn
  - Instagram
  - Twitter/X
- 🧠 AI-generated:
  - Captions
  - Hashtags
  - Engagement hooks
  - AI image prompt suggestions
- ⚡ Fast and interactive Streamlit UI
- 🎨 Modern responsive interface

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **NVIDIA NIM API**
- **Meta Llama 3.1 70B**
- **OpenAI SDK**

---

## 📌 Problem Statement

Businesses and content creators spend significant time manually creating social media posts for different platforms.

This project automates the content creation workflow using AI, helping users:
- save time
- improve productivity
- generate engaging content instantly
- streamline marketing workflows
